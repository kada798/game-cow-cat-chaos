# 奶牛猫大作战 · Moo Cat Mayhem

主角：希小乐 / Xiaole。一只聪明、调皮又黏人的奶牛猫。与它斗智斗勇，看它从四个月大的小猫慢慢长大，回看那些笑中带泪的日常。

## 当前版本

十三幕流程粗版：保留原四幕完整玩法，加入一幕直接点击脚的凳子玩法、五幕主要玩法骨架和三幕叙事互动。新增内容先使用复用插画、三步点按和简单位置变化，正式拖动与路线策略尚待下一轮实现。

完整脚本、真实事件依据、分镜与后续玩法见 [STORYBOARD.md](STORYBOARD.md)。运行流程及模块见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 运行与试玩

直接用浏览器打开 index.html，无需安装、服务器或网络请求。适配电脑、手机和平板。

默认从第一幕开始。顶部可以上一幕、下一幕或选择章节；完成互动后才启用下一幕。原四幕保留自己的重玩和声音控件。新增幕可以重玩，第十三幕摸头后可从头开始。

章节选择允许直接回看，进度仅在当前页面会话中保留，刷新从头开始。

## 中英法三版

顶部语言选择支持中文、English、Français，切换即时更新剧情、当前提示、按钮、章节名称、图片说明和无障碍标签，不会重置关卡、步骤、脚印、音效设置或通关进度。

- 中文入口：`index.html?lang=zh`
- 英文入口：`index.html?lang=en`
- 法文入口：`index.html?lang=fr`
- 可与章节预览组合，例如 `index.html?lang=fr&scene=bedtime`。

首次语言选择的优先级：有效链接参数 → 记住的手动选择 → 浏览器首选语言 → 中文。手动选择会更新链接中的 lang 参数，并尝试保存在本地；即使浏览器禁止本地存储，也可在本次打开时切换。重新加载会重置游戏进度，但语言偏好可以保留。

三种语言共享游戏与素材，离线运行；没有翻译服务或外部请求。英法文使用 Xiaole，十二斤写为 6 kg。

语言文件位于 `locales/zh.js`、`locales/en.js`、`locales/fr.js`，目前每种语言各有 184 个对应文本条目。`i18n.js` 负责选择语言和更新文本。中文剧情仍是 `story.js` 的叙事依据，开发用分镜、来源与实现计划保留中文。

新增玩家文本时，在三个语言文件中添加相同的键，并通过 `catI18n.write()` 或 `catI18n.attribute()` 绑定中文原文；绑定会在语言切换时自动更新。修改中文原文时需同步 `locales/zh.js` 的对应条目。不要直接覆盖声音标签的整段内容，以免移除复选框。

## 文件与预览

- index.html：场景原素材与入口。
- stool.js：第三幕跳起拍脚、移脚后趴下，以及动画取消与重玩。
- story.js：十三幕文案、分镜、来源标注和新增互动骨架。
- story.css：新增回忆画面和章节导航。
- script.js：按章节ID切换、进度、原玩法接入、声音及事件记录。
- ambush.*、yarn.*、dad.*、teddy.*：原四幕独立控制器，保留其玩法。
- viewport.js：原有视口与坐标转换。
- assets/art-v1/：原有透明素材。
- tests/story.cjs：十三幕完整流程、回看、重玩、打断与响应布局检查。

开发预览使用 index.html?scene=章节ID。兼容 ambush、yarn、dad、teddy，新增 stool（第三幕）、arrival、footprints、bedtime、morning、study、departure、photos、ending。未知ID回到第一幕。

## 验证

已有浏览器测试依赖声明在 tests/package.json。安装测试依赖与 Playwright Chromium 后，可在 tests 中运行 npm test；单独验证十三幕使用 npm run test:story。游戏本身不需要这些依赖。

三语专项使用 `npm run test:i18n`：检查词条覆盖、三版十三幕完整通关、切换不丢进度、原关卡动画不中断、语言选择优先级、存储被禁用，以及六组视口下的三语布局。原场景专项测试固定中文，继续验证原玩法。

第三幕专项使用 `npm run test:stool`，覆盖直接点脚、移脚后才趴下、重玩、语言切换、键盘、动画打断、转屏和图片加载重试。
